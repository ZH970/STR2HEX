# STR2ASCII - 字符串转 ASCII 十六进制码工具

## 功能说明

- 输入 4 位 ID（大写字母 F/G/H/I + 三位数字，如 F001）
- 输出 ASCII 十六进制码（如 46 30 30 31）
- 支持前缀 85 07 选项
- 自动记录转换历史到 CSV 文件
- 固定设备 ID 解锁/查询命令，方便复制
- 勾选 前缀85 07，转换结果显示时会在前面多加85，但是历史记录存储还是原来的转换结果存储


## 这个工具是干什么的？
把 4 位编号（比如 F001）转换成电脑底层用的十六进制码（比如 46 30 30 31），
每次转换都会自动记录到本文件夹里的 conversion_log.csv 文件里，
如果某个编号已经转换过了，会提示你"重复"。


## 怎么打开程序？
双击这个文件夹里的 STR2ASCII.exe 就可以了。
不需要安装任何东西，不需要联网，不需要管理员权限。


## 怎么使用？一步一步来
1. 程序打开后，左边是【输入框】，右边是【结果框】。
2. 在左边输入 4 位编号，例如：F001
   （注意：必须是大写字母 F、G、H、I 开头的 4 位，
    后面跟 3 个数字，比如 F001、G123、H456、I999 都可以）
3. 点中间下面的蓝色【转换】按钮（或者按键盘回车键）。
4. 右边就会显示转换结果，比如输入 F001 会显示 46 30 30 31。
5. 需要复制结果的话，点【复制结果】按钮，然后到别处粘贴即可。
6. 程序下方会显示最近的转换记录，方便你核对。


## 格式要求
- 只能输入 4 个字符，不能多不能少。
- 第一个字符必须是大写字母：F、G、H、I（其他字母不行）。
- 后面 3 个必须是数字 0-9。
- 举例：F001、G123、H456、I999 都是合法的。
- 反例：F0010（5位）、A001（字母A不行）、f001（小写不行）。
输入不合法时，程序会弹窗提示，把正确的格式告诉你，重新输入即可。


## 转换记录（CSV 文件）
- 每次成功转换，会自动记录到本文件夹的 conversion_log.csv 里。
- 这个文件用 Excel 或记事本都能打开查看。
- 同一编号第一次转换会记录，第二次再转换同一个编号：
  不会重复记录，但会提示"警告：该 ID 已转换过"。
- 程序下方的【清空历史】按钮可以把记录全部清空（慎用！）。

## 重要提醒（请务必阅读）
1. 请把 STR2ASCII.exe 和它生成的 conversion_log.csv
   放在同一个文件夹里，不要分开，也不要随意删 conversion_log.csv。
2. 程序运行时，请不要用 Excel 打开 conversion_log.csv。
   如果打开了，转换时会提示"文件被占用"，关掉 Excel 再试即可。
3. 如果杀毒软件（360、火绒等）提示"是否允许运行"，请选择"允许"。
4. 不要双击打开两个窗口。如果已经开了一个，再双击第二个，
   会提示"程序已在运行"，这是正常保护，关掉多开的窗口即可。
5. 程序关闭后记录仍然保留，下次打开还能看到历史记录。
6. 如果程序打不开或报错，请检查：
   - 是不是被杀毒软件拦截了？（添加到信任/白名单）
   - 是不是放在只读的文件夹（比如某些公司共享盘、系统盘 Program Files）？
     建议放在自己有权限的文件夹里。
7. 升级/更换电脑时，把整个文件夹复制走即可，记录会一起带走。

## 常见问题
问：打开程序没反应？
答：稍等 1-2 秒，程序启动需要解压一下，属正常现象。
   如果一直没反应，看看是不是被杀毒软件拦截了。

问：提示"文件被占用"？
答：你正在用 Excel 打开 conversion_log.csv，关闭 Excel 再试。

问：提示"程序已在运行"？
答：已经开了一个窗口，不需要再开第二个，用现有的就行。

问：转换结果怎么和表格里对不上？
答：确认输入是 4 位、大写 F/G/H/I 开头。比如 F010 对应 46 30 31 30，

问：不小心点错了，想删掉某条记录？
答：程序不支持单独删除某一条。可以点【清空历史】全部清空，
   或者用 Excel 打开 CSV 手动删除那一行再保存（但程序运行时别改）。


## 技术信息
- 程序：Python 3.10 + tkinter，PyInstaller 单文件打包
- 记录文件：conversion_log.csv，UTF-8 编码
- 格式规则：正则 ^[FGHI]\d{3}$
- 单实例保护：Windows 命名互斥量，防止多开导致记录文件损坏

## 打包命令

```bash
pyinstaller --onefile --noconsole --name STR2ASCII main.py
```

### 参数说明
- `--onefile`：打包成单个 exe 文件
- `--noconsole`：不显示控制台窗口
- `--name STR2ASCII`：输出文件名

### 使用 --clean 参数的场景
- 代码结构发生重大变化（如重命名模块、删除大量文件）
- 遇到奇怪的构建错误，怀疑是缓存问题
- 切换 Python 版本或 PyInstaller 版本后

## 打包注意事项

### 1. Python 环境依赖的 DLL

使用 QwenPaw Python 发行版时，需要手动添加以下 DLL 到 `STR2ASCII.spec`：

| DLL 文件 | 来源模块 |
|---------|---------|
| `ffi.dll` | `_ctypes.pyd` |
| `libcrypto-3-x64.dll` | `_hashlib.pyd` |
| `liblzma.dll` | `_lzma.pyd` |
| `libbz2.dll` | `_bz2.pyd` |
| `tcl86t.dll` | `_tkinter.pyd` |
| `tk86t.dll` | `_tkinter.pyd` |

### 2. spec 文件配置

在 `Analysis` 的 `binaries` 参数中添加：

```python
binaries=[
    ('D:\\QwenPaw\\Library\\bin\\ffi.dll', '.'),
    ('D:\\QwenPaw\\Library\\bin\\libcrypto-3-x64.dll', '.'),
    ('D:\\QwenPaw\\Library\\bin\\liblzma.dll', '.'),
    ('D:\\QwenPaw\\Library\\bin\\libbz2.dll', '.'),
    ('D:\\QwenPaw\\Library\\bin\\tcl86t.dll', '.'),
    ('D:\\QwenPaw\\Library\\bin\\tk86t.dll', '.'),
],
```

### 3. 常见错误处理

**错误：`ImportError: DLL load failed while importing _ctypes`**

原因：缺少 `ffi.dll`

解决：在 spec 文件中添加 `ffi.dll` 路径
